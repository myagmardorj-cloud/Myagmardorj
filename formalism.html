⚠️ This page defines the mathematical objects used in this computational study. No proof of the Riemann Hypothesis is claimed. All results are computational observations requiring independent replication.

Mathematical Formalism

Exact definitions, notation, and computational pipeline — v0.3 · May 2026

Definitions

Basic Objects

Definition 1 — Riemann Zeros
Let \(\rho_n = \frac{1}{2} + i\gamma_n\) denote the non-trivial zeros of \(\zeta(s)\) with \(\gamma_n > 0\), ordered so that \(\gamma_1 \leq \gamma_2 \leq \cdots\)
Source: Odlyzko zero tables. Three blocks used: zeros2 (T ≈ 74,920), zeros3 (T ~ 10¹²), zeros4 (T ~ 10¹³).
Definition 2 — Zero Spacings
\[\delta_n = \gamma_{n+1} - \gamma_n, \qquad \bar\delta = \frac{1}{N}\sum_{n=1}^{N}\delta_n\]
Raw spacings, not unfolded. Mean spacing varies with height T.
Definition 3 — Spacing Covariance at Lag h
\[C(h) = \frac{1}{N-h}\sum_{n=1}^{N-h}\bigl(\delta_n - \bar\delta\bigr)\bigl(\delta_{n+h} - \bar\delta\bigr)\]
The observable we compute. Evaluated at prime lags h = p.
Definition 4 — High-T Unfolded Normalization
\[\tau_p = \frac{\log p}{\log(T / 2\pi)}\]
Critical: using \(\tau_p = \log p / 2\pi\) (low-T formula) gives r ≈ 0.4–0.6 with no visible pattern. The high-T formula was selected after observing this failure — introducing potential selection bias (see Limitations).
Definition 5 — BK Predictor
\[B(p) = \frac{(\log p)^2}{p}\]
From Bogomolny–Keating (1996). Predicts the form of prime-dependent corrections to pair correlation statistics.
Definition 6 — Empirical Amplitude
\[A(p) = C(p)\]
The spacing covariance evaluated at prime lag p. We test whether A(p) ~ B(p).
Observable

Main Correlation

We compute the Pearson correlation coefficient between the empirical amplitudes and the BK predictors across the first 12 primes (p = 2, 3, 5, ..., 37):

\[r = \mathrm{Pearson}\bigl(\{A(p)\}_{p \leq 37},\; \{B(p)\}_{p \leq 37}\bigr)\]

Observed values: r = 0.9783 (zeros2), r = 0.9992 (zeros3), r = 0.9421 (zeros4).

Null Models

Control Distributions

Null 1 — Permutation Test
Randomly permute the zero spacings \(\{\delta_n\}\), recompute C(p) and r. Repeat N = 500 times. Expected: r ≈ 0 under H₀.
Null 2 — GUE Surrogate
Replace zeros with synthetic Wigner–Dyson distributed spacings: \(s \sim \frac{\pi}{2}s\,e^{-\pi s^2/4}\). Compute r on surrogate. Repeat N = 300 times.
Null 3 — Composite Lags
Replace prime lags {2,3,5,...,37} with composite lags {4,6,8,...,22}. Compute r. Expected: r ≈ 0 if signal is prime-specific.
Statistical Limitations

Why These Results Are Not Conclusive

Limitation 1 — Selection Bias
The high-T normalization was chosen after observing that low-T gave weak results. This post-hoc selection inflates the apparent correlation.
Limitation 2 — Small Sample
Pearson r with n = 12 data points is sensitive to outliers. Functional form coincidence cannot be excluded.
Limitation 3 — Autocorrelation
Covariances C(p) and C(p') for nearby primes are not independent. Effective degrees of freedom < 12. Naive p-values are unreliable.
Limitation 4 — Unknown Asymptotics
Behavior of r as N → ∞ is unknown. Tested only up to N = 10,000. Signal may be a finite-window artifact.
Limitation 5 — No Theoretical Derivation
The empirical constant R(p) = A(p)/B(p) ≈ 16.5 has no analytic explanation. The connection to BK (1996) is heuristic.
Computational Pipeline

Step-by-Step

01
Load zeros — Read γₙ from Odlyzko plain-text file (one value per line).
02
Compute spacings — δₙ = γₙ₊₁ − γₙ, center: δₙ ← δₙ − δ̄.
03
Compute C(p) — For each prime p ≤ 37: C(p) = mean(δₙ · δₙ₊ₚ) over n.
04
Compute B(p) — B(p) = (log p)² / p for each prime p.
05
Pearson r — Correlate {C(p)} and {B(p)} across 12 primes.
06
Null controls — Repeat with shuffled zeros, GUE surrogates, composite lags.
07
Report — r value, naive p-value (uncorrected), null comparison. All caveats stated explicitly.
Explicit Statement
This computational study does not constitute a proof or disproof of the Riemann Hypothesis. The observations are empirically consistent with Bogomolny–Keating predictions but multiple confounds have not been excluded. Independent replication and asymptotic analysis are required.
