# BK Amplitude Law – Яагаад батлагдаагүй вэ?

## Ажиглагдсан зүйл
- p=2 давамгайлсан
- Дараагийн primes-ийн ΔK жижиг

## Боломжит шалтгаанууд

3. Finite size effect (100,000 zeros хангалтгүй)
4. Baseline тооцоололд алдаа байж болох уу?
